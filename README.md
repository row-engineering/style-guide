# Rest of World Style Guide

This style guide documents the core visual identity and design principles for *Rest of World*. It is for designers, editors, developers, and partners working across our digital platforms, products, and branded materials.

It covers how to use our typography, color palette, logos, and components consistently, so everything we make reflects our brand values and stays visually clear.

## What's inside

- **Brand identity**: logo and icon, typography, color, diacritics, components
- **Art direction**: image guidelines
- **Licensing and partnerships**: licensing guidelines, photography, social promotion

## Structure

A static site with no build step.

- `index.html`: the style guide
- `css/`, `js/`, `fonts/`, `images/`: supporting assets
- `archive/`: a previous version of the guide created by our first designer, Jody Mak

To view it locally, open `index.html` in a browser or serve the folder with any static server.
